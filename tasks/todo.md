# NovaSight 用户诉求收尾任务

## 1. 算法责任与公平性地图（S，无依赖）

- [x] 在工作空间内给出感知/检测结果、目标决策、控制、输出的可视化责任图，区分已实现、冲突与建议。
- [x] 每个自检项指向当前存在的代码或测试；标记旧交互地图为历史快照。
- [x] 超时准星明确回退几何中心，并留下旧代码会失败的回归检查（主机通过）。
- 验证：路径存在性检查、地图条目与当前代码抽样核对、文档链接检查。预计 `docs/` 2–3 文件。

## 2. 前端 15 项问题台账（S，无依赖）

- [x] 复用已存在的 [20 项实际问题台账](../docs/frontend-qa-2026-09-21.md)，不重复编造“新发现”；其回归证据指向具体交互测试。
- [x] 标明历史修复与当前现场未知的区别，并记录仍需设备验收的操作。
- 验证：对照现有单元/浏览器测试与当前组件，不用测试数量冒充问题数量。预计 `docs/` 1 文件。

## 3. 前端问题修复（拆成每项不超过 5 文件，依赖 2）

- [ ] 优先修复阻断操作、错误无恢复入口、配置显示与实际不一致的问题。
- [ ] 不在未授权时自动切换模型、打开输出或丢弃编辑。
- 验证：每个修复留一条能在旧代码失败的检查；最后统一运行前端构建、单元与桌面/窄屏浏览器测试。

## 4. 创建模型目录端到端（M，无依赖）

- [x] 只允许模型根目录内的新相对目录，拒绝绝对路径、`..`、符号链接越界和覆盖（主机合同通过）。
- [x] 权限失败或重名时返回具体原因，不改变注册/部署状态；读回目录树（Store 与隔离 API HTTP 测试通过，Jetson 页面待验）。
- [x] 空模型库也可从页面创建并进入文件夹；失败保留输入和原始原因（桌面/窄屏模拟浏览器通过）。
- 验证：后端路径合同、浏览器创建/读回合同。后端和前端各一组小改动。

## 5. 移动或重命名模型文件端到端（M，依赖 4）

- [x] 活动部署或已登记引用默认拒绝；源/目标同目录 manifest 都不被静默拆散。仅允许未登记 Engine 整理。
- [x] 成功后目录树与缓存读回新路径；冲突/越界/符号链接/已登记/manifest 拒绝后原文件仍可用（主机 Store 与隔离 API 测试通过）。
- [x] 页面明确确认路径更改，失败保留草稿和后端原因，不隐式切换部署（桌面/窄屏模拟浏览器通过）。
- 验证：后端路径/manifest/活动部署/回滚合同及浏览器读回。每层分小改动。

## 6. 模型库跨页面与失败恢复（S，依赖 4、5）

- [x] 创建/移动/重命名后当前选择进入新文件夹，目录搜索/排序与部署状态不被隐式改变（模拟浏览器通过；Jetson 待读回）。
- [x] 失败后的前端草稿、后端文件和已保存引用不发生分叉，桌面/窄屏无溢出（主机/模拟浏览器通过；Jetson 待验）。
- 验证：模拟浏览器合同、真实隔离 API 读回。

## 7. Jetson 隔离运行态（M，依赖 3、6）

- [ ] 当前提交构建并记录二进制身份；隔离配置关闭输出和自动连接。
- [ ] 真正页面登录、保存类别配置、配置/effective revision 读回、采集规格与故障详情一致。
- 验证：页面→HTTP→daemon→配置→运行态闭环，留脱敏收据；绝不操作用户正在运行的实例。

## 8. 真实非空 GPU 检测（M，依赖 7）

- [ ] 核实用户选定的采集格式、分辨率和帧率在设备实际生效。
- [ ] 使用匹配模型的真实非空目标，对照有效框、类别、排序/NMS、原始错误和只回传有界最终结果。
- 验证：Jetson 硬件追踪与脱敏样本收据；没有合适画面时保持未完成。

## 9. 公平性与最终交付（M，依赖 1、7、8）

- [ ] 为异常粘附跟随设计可解释的监测/阻断与 dry-run 验证，不提供规避判定策略。
- [ ] 有监督条件下单独验证物理输出/断连；无监督时不进行物理移动。
- [ ] 更新过时文档，检查当前 SHA 的 CI、构建、测试、Jetson 代码/二进制/服务状态后再同步与报告。
- 验证：按需求逐条审计证据；每项未满足则目标保持进行中。
