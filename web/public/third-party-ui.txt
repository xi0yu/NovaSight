NovaSight Studio UI sources

AlgorithmTabs.tsx adapts the controlled selection, segment layout and active
indicator pattern from beUI Tabs. Motion, context and Tailwind integration were
replaced with a fixed four-section CSS layout and native keyboard navigation.
https://beui.dev/components/motion/tabs
https://github.com/starc007/ui-components

EmptyState.tsx and empty-state.css adapt the header/media/title/description/content
composition and layout from shadcn/ui Empty into one React 18 + native CSS component.
https://ui.shadcn.com/docs/components/empty
https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/new-york-v4/ui/empty.tsx

Visual references (no component source copied):
- beUI Range Slider: https://beui.dev/components/motion/range-slider
- shadcn/ui Field: https://ui.shadcn.com/docs/components/field

Rare UI was reviewed but is not bundled. Its animated component interactions were
not needed for the existing fixed navigation. No paid components, third-party
image assets or additional runtime packages are included.

NovaSight Daylight character art was generated using the built-in image tool.
Prompt and asset provenance: src/assets/themes/nova-daylight.prompt.md.
