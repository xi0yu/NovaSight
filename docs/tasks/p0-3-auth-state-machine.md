# P0-3 故障状态区分与状态机

裁判：[冻结契约](../designs/auth-session-contract.md)，不得自行扩展未定义行为。

依赖：P0-1、P0-2 验收通过。

交付：迁移权限、服务端确认终态、原页保留、独立业务核对、真实授权信息。

验收：断网、休眠、重启回到原页；本地期限只核验；真实到期才因授权停止资源；重连不启用硬件。

边界：前端不得自行 required/expired/revoked；身份成功不代表业务 ready；迟到响应不得覆盖终态。

规则与场景：A01/A04/A05/A08/A10；S1/S2/S3/S4/S5。

验证证据统一记录在契约验收记录中；单测、浏览器与真实硬件证据分别注明。

契约 v2 补充：A11–A14；N1–N6。内测空码由后端确认申请，原期限有效时不重置；正式版拒绝；真实授权提前一小时用去重的 info toast 提醒。
