# P0-1 双凭证静默续期

裁判：[冻结契约](../designs/auth-session-contract.md)，不得自行扩展未定义行为。

依赖：无；先实现后端。

交付：访问凭证与续期凭证、HttpOnly Cookie、轮换、私有原子持久化、原机器授权恢复。

验收：跨一小时不掉登录；休眠两小时恢复；普通服务重启恢复身份；持久化失败不假装成功。

边界：续期绝对期限 ≤ 原机器授权期限；重启和刷新不能延长一天授权。

规则与场景：A02/A03/A08；S1/S2/S4/S5。

验证证据统一记录在契约验收记录中；单测、浏览器与真实硬件证据分别注明。

契约 v2 补充：A11–A14；N1–N6。内测空码由后端确认申请，原期限有效时不重置；正式版拒绝；真实授权提前一小时用去重的 info toast 提醒。
