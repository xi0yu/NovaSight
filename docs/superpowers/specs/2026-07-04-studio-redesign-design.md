# NovaSight Studio 页面风格改版设计

## 目标

把当前前端从浅蓝科技控制台调整为更商业化的黑红工业 SaaS 风格。参考视觉以白色玻璃面板、黑色主导航、红色强调色、紧凑指标块和设备控制台质感为主。

## 范围

- 重做全局 `StudioShell` 的顶部栏、品牌区、侧边导航和内容容器。
- 统一按钮、输入框、卡片、指标块、标签和实时画面区域的视觉语言。
- 保留当前 React 页面结构、数据请求、WebSocket、模型、采集、推理和授权逻辑。
- 不修改后端接口、不修改推理链路、不新增测试脚本。

## 页面策略

- 性能指挥台继续作为主入口，视觉重点是实时画面、ROI、推理结果和运行反馈。
- 基础设置、模型仓库、运行配置和授权许可复用同一套 SaaS 控件风格，避免每页独立堆卡片。
- 导航使用编号式纵向按钮，增强产品秩序感。

## 设计原则

- 红色只作为强调色，用于活动导航、主按钮、标题竖线和关键状态，不让页面变成大面积红色。
- 卡片保持白色半透明，阴影轻，边框清晰。
- 指标卡更紧凑，适合 Jetson 实时监控场景。
- 移动端退化为顶部内容 + 横向导航，不强行保留桌面侧栏。

## 验证

- 使用 `pnpm --dir web build` 验证 TypeScript 和构建。
- 通过静态检查确认没有 CSS 溢出和明显的无效选择器。
