# Studio 前端与条件状态评估

日期：2026-09-30。范围：React 前端，不改算法、配置契约和设备控制语义。界面检查不能代替 Jetson 运行验证。

## 上轮漏掉了什么

上轮集中在算法参数的默认画面，没充分覆盖操作后的弹窗、失效数据、权限失败、未保存草稿和窄屏长内容。消费级界面不仅要好看，还必须明确区分“已经保存”“正在请求”“已经执行”和“尚未确认”。

| 位置 | 何时出现 | 评估与本轮处理 |
| --- | --- | --- |
| 首页 | 未配置、运行中、关闭、断连、快照过期 | 过期总开关不再呈现绿色运行结论；采集、感知、目标、输出按实际状态着色。没有目标不代表故障。 |

| 分辨率与帧率 | 查询设备能力后 | 保留格式→分辨率→帧率分组及自动保存；保存与运行值分开。断连后不再声称“运行规格一致”。 |

| 类别与瞄点 | 点击编辑类别 | 保留 cls0–15、选点、权重、保存失败、关闭草稿确认；统一确认框视觉与键盘焦点。 |
| 模型库 | 独立页或管理弹窗 | 标签/推荐草稿上报父级；关闭、页面跳转、刷新/离开浏览器有保护。修复直接打开弹窗时缺少步骤条样式的问题，样式由共用组件自己加载。 |
| 模型筛选 | 搜索、文件类型、标签、推荐状态 | 保留筛选无结果与清除筛选；模型列表不复制成另一套假组件。 |

| 实时日志 | 有记录、筛选无结果、清理失败 | 新增搜索、结果计数、重置筛选、排查编号；清理失败保留记录和重试入口，不重复弹窗。历史警告不再说成正在发生。 |

| 授权 | 初次登录、会话失效、授权更换、退出、失败 | 保留安全流程；授权操作错误在表单附近展示，不再重复弹通知。凭证不回显。 |
| 异常中心 | 点击右上角入口 | 空列表只说明没有异常记录，不据此宣称服务健康。技术详情折叠。 |
| 硬件与单步测试 | 进阶入口、配置未生效、物理位移确认 | 仍须满足安全状态与明确确认；不为减少弹窗而删除物理操作保护。 |
| 延迟与运行证据 | 有统计样本或展开诊断 | 断连不使用旧统计冒充实时；没有采集、排队独立打点时不画虚假延迟分解。 |
| 全局通知 | 保存/操作结果 | 收起来源码和排查编号，扩大关闭目标；避免同一授权/模型/清理失败在多处同时弹出。 |
| 紧急停止凭证 | 停止请求后 | 保留请求中、已确认、未确认三态；关闭提示不等于确认安全。 |
| 页面崩溃 | React 渲染异常 | 提供重试、重新载入与折叠错误详情；提示未保存修改和设备不会自动停止的边界。 |
| 关于与资源页 | 次级导航 | 去掉“虚构 KPI”等开发过程文案；授权未知不当成失效，增加组件许可入口。 |

## 设计取舍

- 已加入：日志搜索与计数、可恢复错误块、旧数据标记、真实回执步骤、预览状态选择器。
- 统一：紧凑标题、灰/蓝/黄/绿/红语义、技术详情折叠、确认框长内容滚动、隐藏控件不参与 Tab 循环。
- 不加入：大宣传横幅、装饰性运行图表、没有后端支持的设备中心/账号/云同步，以及伪造切换进度。这些不能解决当前的使用问题。

## 展示与验证边界

开发预览 `preview.html` 顶部有 18 种状态：完整页面、首页断连/过期、日志、设置两态、模型三态、切换三态、确认两态、登录、授权、安全回执和通知。全部复用正式组件；模拟数据有明确标记。它不进入正式构建的页面入口。

预览只拦截当前实际使用的 fetch 与 WebSocket；如今后新增图片设备流、EventSource 或 XHR，必须扩展隔离检查。状态展示并不验证服务端权限、实际回滚、采集驱动或物理输出。

仍不应宣称已完全解决：

1. 登录后的真实会话到期、网络恢复竞态、许可证退出安全确认，需要完整服务联调；本轮只评估前端流程与模拟失败。
2. 所有采集卡的规格组合、模型加载长耗时、真实停止回执，需 Jetson 实测，不能用模拟截图代替。
3. 模型新建文件夹/改名表单的未提交文本目前不属于标签草稿保护；它们尚未执行时不会更改文件，但离开会丢失输入。
4. 大型主视图和累积 CSS 仍有维护成本。本轮修共用根因，不进行与界面需求无关的全量架构迁移。

## 本轮检查结果

- 生产构建、类型检查、差异空白检查通过；未新增依赖。
- 32 个测试文件中的 164 项 Vitest 用例通过，包含函数、组件和模拟接口集成检查，不等于 164 项纯单元测试或真实使用场景。
- 41 个浏览器用例分别在桌面和 375px Chromium 配置下执行，共 82 次通过；后端接口使用模拟数据，不代表真实设备端到端验证。覆盖导航、授权、模型整理、保存确认、移动布局与动效偏好；新增状态预览检查确认没有真实设备请求。
- 手动打开模型弹窗及窄屏切换失败窗口，确认步骤条样式独立加载、主要按钮可见。
- 未提交、推送或同步 Jetson。已有后端和算法修改保留，未作为本轮前端改动处理。
