# 桌面工作台体验调整

以用户认可的首页、开火稳定页作为视觉参照，沿用暖白底、粉色强调、圆角卡片与现有角色插图。主要目标是减少寻找控件、反复滚动和重复说明。

## 行为与布局

- Toast 统一为三秒。显示剩余秒数，进度条使用线性缩放动画，与关闭计时共用 `TOAST_DURATION_MS`；挂载延迟通过负动画延迟补偿。关闭提示不删除错误历史或表单错误。
- 设备管理限制在 1040 px 工作区内。设备、画质、识别范围按顺序呈现；手动路径入口移到常用画质选择之后，避免打断配置流程。卡片不再为了齐高拉出大块空白，识别区域示意改用浅色背景。
- 保存规格与实际运行规格继续分别展示，保存成功不会被当成运行验证成功。真机流程沿用现有扫描、规格读取、配置保存 API。
- 前端预览可扫描 `/dev/preview0`、选择 1080p 的 60/120 FPS 并在本页保存。样例由 `previewNetwork.ts` 拦截生成，不产生真实设备 API 请求；不冒充真机连接、落盘或运行验证。
- 参数页采用与开火稳定页一致的介绍区与圆角设置卡。“搜索范围”和“启动响应”在桌面并排显示，示意图默认收起，保留可展开的范围预览。四个调校分区、键盘切换、草稿保护、自动保存、校验和高级设置继续可用。
- 日志新增来源筛选、暂停查看、恢复实时与新记录数量。暂停只冻结当前显示的数据，流接收继续工作；恢复保留搜索、等级和来源筛选。
- 本机操作记录使用“采集、模型、算法参数、鼠标协议、授权、日志、运行、操作”等来源名称。后台自带的事件标签保留。
- 日志表头在列表内固定，长记录可展开查看原始证据；清理失败保留记录并显示错误。窄屏筛选条可横向滚动，页面本身不横向溢出。

## 清理依据

对生产入口 `main.tsx` 和预览入口 `preview.tsx` 的静态导入、重导出、动态 import 做引用遍历，并单独核对使用点：

- 删除未引用的 `features/motion/trajectoryCapture.ts`（289 行）与 `LaunchReadinessPanel.tsx`（43 行）。运行就绪判定仍由现有首页逻辑负责。
- 删除已被“关于”内授权面板取代的独立 `LicenseView` 组件，保留并明确命名 `LicenseGate.tsx`。相关测试调整为 `LicensePanel.test.tsx`。
- 删除旧 `km-box.css` 页面样式；仍在使用的设备功能导航样式移回 `studio-settings.css`。
- 删除参数页重复的“参数工作台”提示、无作用的页签数字与隐藏装饰节点，清除对应样式及旧启动提示样式，共 22 条已无引用的 CSS 规则。
- 再次遍历后，未发现脱离两个入口的应用 TS/TSX/CSS 模块；测试 setup 和 Vite 类型声明是有意保留的工具文件。此检查不等于证明每一个导出或每一条动态类名都已无冗余。
