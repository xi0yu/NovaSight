# 鼠标协议交互与授权到期处理

## 本次行为

- 点击协议卡片直接选中并启用；点击“空”卡片切回静默输出。成功回执到达后更新选中边框，失败保留原选择。
- 卡片之间可以直接切换。“配置协议”默认打开当前选中的物理协议；选中“空”时点击只投递“空协议无需配置” Toast，即使已有其他协议也不自动跳转到其配置。
- “配置协议”与“新增协议”并列。配置 Dialog 可选择已有协议，编辑不会隐式启用该协议；有未保存修改时禁止切换配置对象。运行期间仅允许查看连接配置。
- 真机保存按钮为“保存并写入文件”，沿用 `/api/config` 的版本校验、运行时应用、YAML 原子写入与失败补偿。预览仅修改当前页面内存。
- Toast 显示独立的三秒倒计时和线性进度条，到时消失；错误记录与表单内错误继续保留。后续布局调整与最新检查见 [桌面工作台体验调整](desktop-workspace-refresh-2026-10-09.md)。
- 授权管理并入“关于” Dialog。直接展示“设备模型 ID、到期时间、授权类别（测试/正式）”三项信息，倒计时附在到期时间下方，不再以“临时测试授权”作为标题。未核实的旧授权文件不冒充正式授权；旧 `page=license` 地址打开“关于”，关闭后返回首页。
- `device_model` 由服务端读取设备树/DMI 或 macOS `hw.model`，无法获取时明确标记未知。此字段用于显示设备型号，不是许可证的设备绑定标识。
- Debug 源码启动生成的临时授权码固定从本次 daemon 启动起有效 24 小时。退出、重新登录或重复激活同一码不延长期限；临时授权仍不落盘。正式许可证保持原有签名验证和有效期。
- 临时期限同时由墙上时间和单调时钟约束，修改系统时间不能让本次临时授权无限延期。
- 授权看门狗按到期时间提前调度检查，到期调用紧急停止；主链处于停止状态时也发出取消请求，覆盖正在处理的模型任务。停止采集、推理和设备输出所属的主链资源，关闭残留预览。失败保持访问锁定并重试；保留 HTTP/控制服务与前台以便重新授权。
- 失效期间保留停止信号，阻止此前已经排队的启动或模型任务在停止后重新开启资源；重新授权成功才释放该信号。
- 前端到期计时独立于是否打开“关于”，到期锁定操作并回到授权入口。硬件清理结果仍以 daemon 为准，前端不会凭计时器宣称硬件已经安全停止。
