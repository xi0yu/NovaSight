# Studio 1.10.535 产品体验契约

本轮依据用户八项反馈与独立产品经理源码审阅制定。与授权契约共同验收；后续新增交互先修订规则。用户最新要求覆盖历史“关于包含授权管理”的决定。

## 使用者与视觉方向

使用者是在电脑上操作自己设备的普通用户，希望理解权益、选择画面与模型、快速保存和恢复设置。产品应像有角色陪伴的视觉工作台：友好、明快、状态可靠。

领域：画面、模型、算力、设备、配置、授权权益。延续已有二次元角色和粉彩系统，以奶白背景、莓粉品牌、浅蓝授权、绿色确认、琥珀等待组成视觉语言。标志性表达是角色陪伴的专属授权卡和真实的采集→推理→控制链路。拒绝把排障表格当产品介绍、把重复全屏等待当步骤、把发现路径当可用证明。

桌面正文 14px/22px；分组 18px，主要权益标题 24px；4/8/16/24px 间距。已有组件、图标和角色优先，不新增主题系统。状态始终有文字，装饰不遮挡内容、操作或错误。

## 本轮工单与验收

1. **P0 关于只读与权益表达**：拆开授权展示和管理组件；关于只保留关闭控件。以“看清画面 / 发挥模型算力 / 掌控设备与设置”表达有效授权能力，每项文案由实际 features 支持。未知/失效不得显示已解锁能力，不虚构价格、等级、精度、帧率或特权。
2. **P0 刷新一次过渡**：连接、核验、组件加载共用一个品牌启动框架；内部状态机不合并。提前并行加载控制台代码，不显示三套中间页。已打开页面恢复时保留原页与草稿；真正终态只能服务端确认。
3. **P0 可用设备预检查**：列表各项由真实能力查询区分检查中、可选择、不可用、检查失败；检查中/未确认/不可用均禁选，保留重新扫描。不可用用图标、原因与灰色表达；检查失败不能伪称硬件坏了。手输路径仍可单独核验，不启动采集。
4. **P1 快速备份恢复**：导出和导入主操作直接可见；备份使用当前持久配置。导出反馈仅说明已发起下载；读取与写入错误都记录。导入先验证格式并预览人类可读差异，一次确认后写入文件并回读。保留 CAS、未保存草稿保护和输出开关；冲突重新确认，未知写超时不重放。测试下载文件→修改→恢复→再次读配置，不能仅检查按钮点击。
5. **P1 问题记录闭环**：移除设置技术折叠项与 revision 展示。前端操作结果/失败限量脱敏保留在当前浏览器，刷新后仍可查看；现有服务日志继续展示服务事件。实时日志提供导出，含产品版本、时间、来源、关联请求编号与错误证据；用户主动清理有效，存储不可用不能阻断业务。浏览器本地记录不是服务端长期审计，不能宣称自动远程收集。
6. **P1 模型加载与语言**：已读取列表更新时保留列表与选择，初次读取使用与最终布局一致的局部骨架。打开模型管理只发必要请求，去掉静态+动态重复模块引用及重复刷新请求。改用“可选择 / 切换时检查 / 已部署 / 正在使用”等对应事实的语言，验证记录不能等同当前可运行。
7. **P1 版本管理**：前后端公开包与发布元信息统一 `1.10.535`，构建 UUID 独立保留。以后按 SemVer：兼容修复增加 patch，兼容功能增加 minor 并归零 patch，不兼容 API 增加 major 并归零其余；不得把三段版本当小数或追加第四段日期。
8. **P1 视觉与代码管理**：核对 1440/1024/375px，键盘与关闭返回、异步空态/失败/重试、3 秒 toast。复用现有组件和纯数据接口，采用具业务含义的命名，删除死 UI 和无用 props；不为追求公司风格重排无关代码或新增依赖。

## 反向验证

- 有效授权刷新：一个启动框架→服务端身份确认→真实授权确认→原页面；HTML 首次响应即展示同一启动框架，代码加载与身份核验并行，不能因为等待转成授权页。
- 断网/重启：已打开页面保留；状态仍只能 checking/reconnecting；读取成功后核对业务，不重启输出。
- 关于：打开/关闭只读产品信息，没有写 API；授权管理只能设置中主动操作，退出仍先确认并安全停止。
- 导入损坏文件：不产生写请求，操作失败留下可读记录；导入超时：不重发，核对真实状态后由用户决定。
- 不可用输入：能力核验确认不可用后禁选；查询失败明确待确认，重新扫描可恢复；不保存未确认路径。

命名参考 [Google TypeScript 风格指南](https://google.github.io/styleguide/tsguide.html)，保留本库 React/Rust 约定，以小范围、可评审、行为可验收的提交管理代码。未核实 Twitter 当前内部规范，不将推断写成事实。版本规则遵循 [SemVer](https://semver.org/lang/zh-CN/)。

工具链：pnpm 11 安装器与脚本依赖检查的全局虚拟存储默认值不一致；项目显式固定现有 `enableGlobalVirtualStore: true`，安装使用冻结锁文件，不改依赖版本，避免构建期间意外重装依赖。
