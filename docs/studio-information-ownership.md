# Studio 信息展示归属

目标：Studio 默认界面服务正常用户的启动、观察、调参和停用；累计计数、协议回执、generation、原始诊断和内部证据只在排障时展开。

## 展示原则

1. 当前页只放该场景的主操作和当前状态，不把后台链路证据铺在首屏。
2. 同一个事实只在一个主位置展示；其他页面需要时只给状态摘要或折叠诊断。
3. 配置页展示用户能调的参数和保存/运行是否一致，不展示流水账式遥测。
4. 控制页展示预测-控制-限制-输出链路是否通过；细分字段用于诊断，不作为正常用户的主内容。

## 信息归属表

| 页面 | 默认展示 | 折叠诊断 | 避免重复展示 |

| 模型推理 | 推理 FPS、结果 FPS、结果新鲜度、最近检测、当前模型、模型装载状态、置信度/NMS 配置、ROI 输入预览 | nvinfer 输入/输出计数、DetectionBatch 发布/消费、PTS 匹配、generation、模型输入细节、后处理输出证据 | 运行置信度/NMS 不再在模型工程详情里重复出现 |

## 后续清理队列

- 控制页可以继续把目标筛选、输出、设备回执拆成“当前状态摘要 + 诊断详情”，避免一屏里出现过多 KV。
- 参数页不放独立摘要指标条；配置画像、输出门、预测开关和配置入口本身就是主内容。
- 主题适配要以同一批控件令牌为准，优先修正按钮、开关、折叠区、输入控件在不同主题下的对比度。
- 参数控件继续从“输入框 + 按钮”迁移到分段控制、开关、滑杆、预设和高级折叠，但保持同一运行方式和同一配置语义。
